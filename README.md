# Bangla Multimodal RAG — Objective-Aligned Version

This version is aligned with the thesis objective:

**Docling extraction → chunking → embedding → vector store → question embedding → retrieval → LLM answer → evaluation**

No extractive-first answer bypass is used. The final answer is always generated by the selected local Ollama LLM from the retrieved chunks.

## Main features

- Bangla PDF extraction using Docling.
- Text, table, structure/list, and image-caption chunks.
- OCR strategies: `auto_best`, `native_only`, `force_selected_ocr`, `compare_easyocr_tesseract`.
- Embedding models:
  - `nomic-embed-text-v2-moe:latest`
  - `BAAI/bge-m3`
  - `intfloat/multilingual-e5-base`
  - `sentence-transformers/paraphrase-multilingual-mpnet-base-v2`
  - `sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2`
- Direct Bangla retrieval and translated-English retrieval comparison.
- Embedding model comparison.
- QA logging for thesis evaluation.
- Batch evaluation scripts and Excel template.

## Image handling

Raw images are not embedded directly. The system handles images as:

```text
PDF image/chart/diagram
↓
Docling extracts image reference
↓
optional image caption text is generated
↓
image caption becomes an image chunk
↓
caption text is embedded and stored in vector store
```

## Translation comparison

Two vector indexes are built for each embedding model:

```text
direct      = Bangla chunks embedded directly
translated  = English-translated chunks embedded for translated retrieval
```

During question answering:

```text
direct mode:
Bangla question → Bangla question embedding → direct vector index → retrieved chunks → LLM

translated mode:
Bangla question → English translation → English question embedding → translated vector index → retrieved chunks → LLM
```

## Evaluation

All quantitative results are produced by a single harness, `scripts/evaluate_metrics.py`,
run against a 28-question ground-truth set (`data/eval_ground_truth.csv`):

```powershell
# 1. Retrieval-only sweep: Hit@1/3/5 and MRR for every (embedding model, mode) pair
python scripts/evaluate_metrics.py retrieve_only `
  --ground-truth data/eval_ground_truth.csv `
  --out results/retrieval_eval.csv `
  --embedding-models "nomic-embed-text-v2-moe:latest" "BAAI/bge-m3" "intfloat/multilingual-e5-base"

# 2. Full generation sweep (retrieval + LLM), one run per mode
python scripts/evaluate_metrics.py generate `
  --ground-truth data/eval_ground_truth.csv `
  --embedding-model BAAI/bge-m3 --mode direct --llm qwen2.5:3b-instruct `
  --out results/generation_eval_direct.csv
python scripts/evaluate_metrics.py generate `
  --ground-truth data/eval_ground_truth.csv `
  --embedding-model BAAI/bge-m3 --mode translated --llm qwen2.5:3b-instruct `
  --out results/generation_eval_translated.csv

# 3. Human-eval pass (semantic correctness, groundedness, fluency)
python scripts/build_human_eval.py

# 4. Aggregate everything into thesis-ready summary tables
python scripts/evaluate_metrics.py aggregate `
  --retrieval-csv results/retrieval_eval.csv `
  --generation-csv results/generation_eval_direct.csv results/generation_eval_translated.csv `
  --out-dir results/aggregate
```

Metrics reported: Hit@1/3/5, Mean Reciprocal Rank (retrieval); Exact Match, token-level F1,
human-judged correctness/groundedness/fluency (generation); retrieval/generation/end-to-end
latency. See `thesis.tex` Chapter 5 and Appendix B for full metric definitions and results.
